# Secure Gallery Access Tracker

## Project Overview
The Secure Gallery Access Tracker is a Flask-based web application for tracking
guests and employees entering and leaving an art gallery and its individual rooms.

## Team Members

- Brandon Renner

## Technology Stack
- Python
- Flask
- HTML/CSS
- Jinja
- SQLAlchemy
- SQLite

## User Roles
- Guest/User
- Employee
- Administrator

## Core Functionality
- User authentication
- Gallery entry/exit tracking
- Room entry/exit tracking
- Current occupancy
- Historical event searches
- Administrative functions
- Audit logging
